# Contributing

1. Create a branch from `main`.
2. Keep production data and secrets out of the repository.
3. Preserve the distinction between candidate places and officially approved shelters.
4. Keep vulnerable-person information aggregated and privacy-safe.
5. Run `node --check public/app.js` and `docker compose config --quiet`.
6. Build and smoke-test with `docker compose up -d --build`.
7. Submit a pull request describing user impact, evidence changes and screenshots.
