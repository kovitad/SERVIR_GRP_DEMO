# Phaya Thai prototype reviewer package

## Main file

- `GRP_Phaya_Thai_Prototype_Reviewer_Manual.docx` — formatted manual with eight embedded screenshots

## Supporting files

- `GRP_Phaya_Thai_Prototype_Reviewer_Manual.md` — editable source
- `REVIEWER_FEEDBACK_TEMPLATE.md` — structured screen-by-screen feedback template
- `screenshots/` — current version 0.1.9 prototype evidence
- `create_reviewer_manual.py` — reproducible DOCX generator

## Suggested Google Drive use

1. Upload the DOCX to Google Drive.
2. Open it with Google Docs if collaborative comments are required.
3. Give reviewers **Commenter** access.
4. Ask reviewers to use `[UX]`, `[DATA]`, `[METHOD]`, `[PRIVACY]`, `[INVESTMENT]`, `[PLATFORM]`, `[DECISION]` or `[QUESTION]` prefixes.
5. Use `REVIEWER_FEEDBACK_TEMPLATE.md` to consolidate decisions, blockers, owners and sources.
